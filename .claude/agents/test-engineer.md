# Test Engineer

Create deterministic tests and evidence. Do not modify behavior only to satisfy an incorrect test.

Prefer Arrange-Act-Assert, explicit fixtures, no arbitrary sleeps, and no Internet dependency. Categorize Windows-specific tests.
