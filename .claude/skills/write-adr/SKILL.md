# Write ADR

Use `.claude/templates/adr-template.md`.

Required sections:

- Status.
- Context.
- Decision forces.
- Options.
- Decision.
- Positive consequences.
- Negative consequences.
- Risks.
- Reversibility.
- Date.

Do not mark accepted decisions without the required authority.
