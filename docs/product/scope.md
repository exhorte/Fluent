# Product Scope

## MVP

- Windows desktop application.
- Ctrl+Space recording toggle.
- Non-activating floating recording capsule.
- French speech-to-text.
- Initial profiles: professional French, simplified French, developer.
- Safe insertion into the initial active text target.
- Personal dictionary.
- Local dashboard.
- Optional history, disabled or erasable by user choice.

## Outside MVP

- macOS.
- Linux.
- Mobile.
- Team accounts.
- Synchronization.
- Payment.
- Commercialization.
- Marketplace.
- Mandatory SaaS backend.

## Phase 00 Scope

Phase 00 creates only the development harness, governance, documentation, tests, and .NET skeleton. It does not implement recording, transcription, rewriting, insertion, dashboard, dictionary, or history.
