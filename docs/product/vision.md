# Product Vision

Fluent aide les utilisateurs Windows francophones à dicter, corriger et insérer du texte localement sans envoyer leur audio ou leur texte à un service Cloud obligatoire.

## Problem

General dictation tools often handle French style, punctuation, technical vocabulary, and privacy tradeoffs poorly. Users need a workflow that stays focused in the target app and respects sensitive contexts.

## Target Users

- Professionals writing French emails, notes, tickets, and reports.
- Developers dictating technical French with commands, paths, versions, and identifiers.
- Users who prefer local processing and minimal data retention.

## Value Proposition

Press Ctrl+Space, speak, stop with Ctrl+Space, transform the transcript according to a chosen profile, and insert the result safely at the original cursor position.

## Expected Result

A reliable local desktop assistant that improves French dictation speed while preserving privacy and preventing dangerous insertion behavior.

## Principles

- Local-first by default.
- Safe target handling before convenience.
- French quality over generic multilingual breadth.
- No invented information during rewriting.
- Documents and tests define reality.

## Non-Goals

- SaaS backend.
- Marketplace.
- Team administration.
- Payments.
- Mobile clients.
- Cloud transcription requirement.
