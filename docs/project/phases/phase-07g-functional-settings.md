# Phase 07G — Paramètres fonctionnels

Statut : BROUILLON — non active ; aucun contrat approuvé

## Objectif

Ajouter une page Paramètres fondée sur des préférences locales validées et réversibles, avec valeurs par défaut sûres.

## Périmètre prévu

- Microphone, hotkey, capsule, profil local, langue et politique d'historique lorsque 07F existera.
- Modèle de préférences versionné, validation, migration de test et réinitialisation explicite.
- États accessibles, navigation clavier, erreurs non bloquantes et documentation des effets.

## Limites

Les secrets, tokens, clés fournisseur et consentement Cloud persistant sont exclus. L'activation et le consentement Cloud restent session-only tant qu'une décision produit, privacy et sécurité n'autorise pas explicitement une autre politique.
